# Cafe Report

Программа читает заказы кофейни из файла `data/orders.csv` и печатает отчёт:
количество заказов, выручку, средний чек и суммы по официантам.

Внешних библиотек нет, нужен только Python 3.10 или новее.

## Структура проекта

```
cafe-report/
├── README.md            описание, запуск, ожидаемый результат
├── requirements.txt     зависимости (внешних нет)
├── .gitignore           что не попадает в Git: .venv, __pycache__, .env
├── app/                 код программы
│   ├── __init__.py
│   ├── main.py          точка запуска: читает заказы и печатает отчёт
│   ├── services/        бизнес-логика
│   │   ├── __init__.py
│   │   ├── orders.py    загрузка заказов из CSV
│   │   └── report.py    сборка строк отчёта
│   └── utils/           мелкие вспомогательные функции
│       ├── __init__.py
│       ├── money.py     форматирование сумм в рублях
│       └── text.py      выравнивание и обработка строк
├── data/                входные данные
│   └── orders.csv       заказы за смену
├── docs/                документация
│   └── about.md         о проекте
└── tests/               автотесты unittest
    ├── test_orders.py
    └── test_report.py
```

- `app/` — весь код, который запускается.
- `data/` — данные, которые программа читает.
- `docs/` — документы для людей.
- `tests/` — проверки кода; файлы начинаются с `test_`.

Удалены как лишние: `заметки.txt`, `main_старая_версия.py`, `orders.cpython-311.pyc`, `.DS_Store`.
Файл `.env` лежит только локально и закрыт в `.gitignore`.

## Запуск

Команды выполняются из корня проекта — из папки, в которой лежит код программы.

```
python -m venv .venv
python -m app.main
python -m unittest discover -s tests -v
```

На Windows вместо `python` может потребоваться `py`, а окружение активируется
командой `.\.venv\Scripts\Activate.ps1`.
