# Text Kit

Учебный набор из 16 функций для строк, чисел, дат и проверки данных. Программа
печатает пример работы каждой функции на заготовленных данных.

## Структура проекта

```
text-kit/
├── README.md
├── app/
│   ├── __init__.py
│   ├── main.py              точка запуска: примеры данных и функция main
│   ├── utils/               общие вспомогательные функции
│   │   ├── __init__.py
│   │   ├── text.py          строки: clean_spaces, shorten, initials, slug
│   │   └── dates.py         даты: parse_date, format_date, is_weekend, days_between
│   └── services/            логика предметной области
│       ├── __init__.py
│       ├── statistics.py    расчёты: average, median, spread, count_values
│       └── validation.py    проверка данных: is_email, normalize_phone, is_phone, password_problems
└── tests/                   19 тестов unittest, по файлу на модуль
    ├── test_text.py
    ├── test_dates.py
    ├── test_statistics.py
    └── test_validation.py
```

## Запуск

Из корня проекта (папка `text-kit`), внешних библиотек нет:

```text
python -m app.main
python -m unittest discover -s tests -v
```

На Windows вместо `python` можно писать `py`.

## По какому признаку разделены функции

По теме, с которой работает функция:

- **utils** — общие инструменты, не привязанные к задаче: работа со строками
  (`text.py`) и с датами (`dates.py`). Их можно взять в любой другой проект.
- **services** — то, что программа делает с данными: расчёты по числам
  (`statistics.py`) и проверка введённых данных (`validation.py`).

Единственная связь между модулями: `validation.py` импортирует `clean_spaces`
из `app/utils/text.py`. Модуль дат один импортирует `datetime.date`.
`app/main.py` только собирает всё вместе: в нём нет других функций, кроме `main`.
